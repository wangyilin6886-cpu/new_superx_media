# SuperX 官网

按 `docs/design/` 的设计稿实现的公司官网首页（12 屏）。
**纯静态外观稿**：没有后端、没有构建步骤，双击 `index.html` 就能看。

## 本地预览

```bash
# 方式一：直接打开
open index.html          # macOS
start index.html         # Windows

# 方式二：起个本地服务（推荐，避免个别浏览器对 file:// 的限制）
npx http-server . -p 8080
# 然后访问 http://localhost:8080
```

## 登录

`login.html` 三个视图：登录 / 注册 / 找回密码，含字段校验、密码显隐、
提交 loading、Google 与 Apple 占位入口。

**这是外观演示，不校验真实凭据**：任何合法邮箱 + 8 位以上密码即可进入。
登录态只写 `localStorage`（`assets/js/auth.js`），不发任何网络请求。
接后端时替换 `SuperXAuth.signIn` 即可。

未登录也能进工作台随便逛，**点发送生成时才拦一次**，且可以选「先看一遍演示」
继续看完整流程（对应设计稿 `05-studio.md §0`：先让人摸到东西，再要账号）。

## 已实现的交互

- 导航滚动后加毛玻璃；产品下拉菜单；移动端全屏抽屉
- 右侧章节轴，滚动高亮，进入产品线时切换成该线辅色
- 滚动进场动画（同组 stagger 60ms）、核心数字滚动计数
- 屏 05 剧集胶片条：点击切换剧集标题与画面色调
- 屏 06 三个 Tab：课件 / 讲课视频 / 练习题，下划线滑动
- 屏 07 Vibe Coding 打字机：左侧日志逐字生成，右侧界面同步"长"出来，循环播放
- 屏 10 客户 Logo 无限横向滚动，hover 暂停并恢复彩色
- 屏 11 月付/年付切换实时改价
- 屏 12 FAQ 手风琴，一次只展开一条
- 全站支持 `prefers-reduced-motion`，关闭位移与自动播放

## 创作工作台（studio.html）

按 `docs/design/05-studio.md` 实现，三栏：左导航 / 中对话流 / 右工作台。
**AI 短视频**、**AI 短剧** 和 **AI App（Vibe Coding）** 三个模式已完整实现，
AI 教育进入后会说明未实现。

壳（左栏、对话流、输入区、状态规范、假播放计时器）四个模式共用，
每个模式只提供四件事：空状态、参数面板、对话剧本、右栏工作台。
加第五条产品线 = 在 `studio.js` 里加一个模式模块。

### AI 短视频 · studio.html?mode=video

打开 → 点「商品链接出片」→ 发送 → 等 agent 跑完 → 点「5 版全出」。会看到：

- 折叠的 agent 步骤行（点开有工具调用明细）
- 脚本产物卡（点击跳到右栏「脚本」Tab）
- 带额度标注的快捷回复
- 5 条并行生成的进度格子，第 ④ 条**故意失败**，演示失败态
- 完成汇报 + 额度消耗
- 右栏工作台：9:16 预览（可播放，字幕跟随分镜切换）、分镜选择、
  镜头明细、其他成片切换、`⊞` 网格模式（多选批量下载）

### AI 短剧 · studio.html?mode=drama

打开 → 点「一句梗概开剧」→ 发送 → 等 agent 跑完 → 点「先出 3 集」。会看到：

- 人物小传 × 8 和分集大纲 EP01–EP20 两张产物卡，分别跳到「角色」「剧本」Tab
- 3 集串行生成，进度条下方显示当前阶段（分镜编排 → 角色渲染 → 配音合成 → 配乐调色）
- EP02 返回一个**黄色警告态**（口型偏差 0.3 秒，片子可用但建议听一遍）——
  和短视频的红色失败态区分开，凑齐了设计稿里的完整状态词汇
- 右栏「剧集」：16:9 预览可播放，**剧本会逐行跟着时间轴高亮并自动滚动**；
  20 格剧集进度条（已完成 / 当前 / 未开始），点未生成的集会提示怎么继续
- 右栏「角色」：角色卡 + 音色 + **形象锁定开关** + 四张参考图（正/侧/笑/怒），
  点锁定按钮能切换状态并解释这对跨集一致性意味着什么
- 右栏「剧本」：20 集大纲，前 3 集标「完整剧本」可跳转
- 右栏「设置」：生成策略默认「先出 3 集」，并标注另一条路要 6 小时 20 额度

选「20 集全出」的话，跑完前 3 集会停下来问要不要继续跑剩下 17 集。

### AI App · studio.html?mode=app

参照 agent 编码工作台的形态做的，壳沿用同一套，但补了两个该模式专有的控件：
顶栏的**环境徽标**（`Next.js 15 · weekly-report`）和输入区右侧的**模型 / 思考强度**选择器。

打开 → 点「团队周报工具」→ 发送 → 等方案出来 → 点「开始生成」。会看到：

- 规划页面结构、设计数据模型两步，展开能看到路由清单和三张表的字段
- 方案产物卡，点开跳到「数据库」Tab
- **逐个文件写入**（8 个），每写完一个右栏预览就多长出一块
- 安装依赖 / 启动开发服务器的命令与输出
- 右栏「预览」：手机 / 平板 / 桌面三档设备框，里面是会逐步长出来的假 App
- 右栏「代码」：文件树（带「新增」标记）+ 代码查看器，极简高亮
- 右栏「数据库」：三张表的字段、类型、外键与行数
- 右栏「部署」：一键部署会把构建日志一行行打出来，完成后给正式地址；
  另有下载源码 zip 与推到 GitHub 两个出口

完成后的快捷回复里选「一键部署」可以继续走部署流程。

快捷键：`⌘\` / `Ctrl+\` 开关右栏工作台。
左上角「新建创作 ▾」可以在四个模式之间切换。
