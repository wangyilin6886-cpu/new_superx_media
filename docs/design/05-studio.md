## 0. 路由与入口

官网上两类按钮要分开，不能都指向同一个地方：

```
「了解 AI 短视频」  →  /video          产品介绍页（卖东西）
「免费开始创作」    →  /studio/video   创作工作台（干活）
「免费生成 3 条」    →  /studio/video   创作工作台
Hero 四色胶囊       →  #video 锚点     首页内分区
```

工作台路由：

```
/studio                   最近项目总览
/studio/video             AI 短视频模式
/studio/drama             AI 短剧模式
/studio/education         AI 教育模式
/studio/app               AI App 模式
/studio/c/:chatId         某一次具体的创作会话
```

**未登录点进来**：直接进工作台，可以正常输入和看演示，
点「生成」时才弹登录 —— 让人先摸到东西，再要账号。

## 1. 为什么是三栏（核心设计判断）

纯对话流的问题：短剧生成会产出剧本、角色卡、20 集分集、每集成片。
这些东西塞进聊天记录里，改第 7 集要往上翻二十屏。

```
┌──────────┬──────────────────────────┬──────────────────────────┐
│ 左：导航  │ 中：对话（说什么）        │ 右：工作台（看什么/改什么）│
│ 280px    │ 弹性                      │ 480px，可折叠/可拉宽      │
└──────────┴──────────────────────────┴──────────────────────────┘
```

- **中栏**是过程：你说 → agent 想 → 调工具 → 汇报。线性，往下滚。
- **右栏**是结果：当前产物的完整视图。不随对话滚动，永远停在最新状态。
- 中栏里的产物卡片是「缩略入口」，点一下右栏就切到它。

右栏可以整个折叠（拖动分隔条或按 `⌘\`），折叠后就退化成 MOVO AI 那种纯对话形态，
适合只想快速出一条的场景。

### 4.2 Agent 回复（分层折叠，这是关键）

agent 的过程信息很多，全展开会淹没结论。**默认只展开结论，过程折叠成一行**：

```

  ✓ 生成脚本 5 版 18s                                              ›       灰色小字

  角度写了 5 版口播脚本，都用痛点式开场。先给你看脚本，确认后再出片。

  ✦ 脚本生成  ✓

  ┌─────────────────────────────────────────────────────────────┐
  │ 📄 口播脚本 × 5                                    查看 →   │ ← 产物卡
  │ ① 换季爆皮的姐妹进来  ② 这瓶我空瓶三次了  ③ 别再买贵的了…  │   点击右栏打开
  └─────────────────────────────────────────────────────────────┘

  要我直接按第 ① 版出片，还是先改脚本？

  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
  │ 按 ① 出片    │ │ 5 版全出     │ │ 我要改脚本   │  ← 快捷回复按钮
  └──────────────┘ └──────────────┘ └──────────────┘

```

```
  └─────────────────────────────────────────────────────────────┘
```

```

  │ 🎬 正在生成 5 条成片                                         │
```

## 5. 底部输入区

```
┌──────────────────────────────────────────────────────────────────┐
│ 告诉 SuperX 你要什么…                                        ⤢  │
│                                                                  │
│ ┌──────────────┐                                                 │
│ │🔗 tmall.com…✕│  ← 已添加的附件                                 │
│ └──────────────┘                                                 │
│──────────────────────────────────────────────────────────────────│
│ ⊕ 添加   @ 引用   🎛 参数        │   逐步确认 ⌄        ┏━━┓     │
│                                                        ┃ ↑ ┃     │
└────────────────────────────────────────────────────────┗━━┛─────┘
```

| 控件 | 作用 |
|------|------|
| `⊕ 添加` | 上传素材 / 粘贴链接 / 从素材库选 / 导入文档 |
| `@ 引用` | @ 一个已有产物（"把 @脚本③ 改短一点"）或 @ 品牌知识库、@ 角色 |
| `🎛 参数` | 展开该模式的参数面板（见 §6/§7），不想打字的人用这个 |
| `逐步确认 ⌄` | **执行模式**：逐步确认 / 自动执行 / 只出方案不执行 |
| `↑` | 发送。生成中变成 `⏹ 停止` |

**「逐步确认 / 自动执行」是最重要的一个开关。**
新手要逐步确认（每一步给你看，你点继续）；
老手要自动执行（说一句话，回来收 30 条片子）。默认逐步确认。

## 8. 空状态（第一次进来看到什么）

最容易被做砸的一屏。不要给一个空输入框就完事：

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│                     ● 你想做什么样的短视频？                        │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐ │
│  │  粘贴一个商品链接，或直接说你的想法…                     ↑  │ │
│  └──────────────────────────────────────────────────────────────┘ │
│                                                                    │
│  从这些开始 ——                                                     │
│  ┌────────────────────┐ ┌────────────────────┐ ┌────────────────┐ │
│  │ 🔗 商品链接出片    │ │ 📝 一段文案出片    │ │ 🎯 竞品同款    │ │
│  │ 粘贴淘宝/京东链接  │ │ 已经写好卖点了     │ │ 发一条参考视频 │ │
│  └────────────────────┘ └────────────────────┘ └────────────────┘ │
│                                                                    │
│  或者看看别人怎么做的：                                            │
│  ┌──────┐┌──────┐┌──────┐┌──────┐   ← 样例作品，点开能看完整       │
│  │ 美妆 ││ 3C   ││ 食品 ││ 服饰 │      对话记录（含 prompt）       │
```

直接给他看一个成功案例是怎么问的，比写十页文档管用。

## 9. 状态与反馈规范

```
排队中   ○ 灰   "队列中第 3 位，预计 1 分 20 秒"
生成中   ▓ 辅色 带百分比进度，超过 30s 显示当前在做什么（"正在合成第 3 个镜头"）
已完成   ✓ 绿
有警告   ⚠ 黄   生成了但有问题（"第 3 个镜头素材匹配度较低，建议替换"）
失败     ✕ 红   给原因 + 至少两个可操作按钮 + 明确"不扣额度"
```

**额度提示**：每次要执行消耗额度的操作前，在确认按钮旁标明消耗量：

```
┌──────────────────────────┐
│ 生成 5 条  · 消耗 5 额度 │  ← 不要生成完才告诉人家扣了多少
└──────────────────────────┘
```

## 10. 响应式

```
≥1440   三栏全开（280 / 弹性 / 480）
1200    右栏收到 400，左栏可折叠成图标条
≤1024   右栏变成覆盖层：默认隐藏，点产物卡从右侧滑出，占 60% 宽
≤768    左栏变抽屉；右栏变全屏 Sheet（从底部滑起）
        对话流全宽；输入框吸底
        产物卡在对话流里直接可播放，不强制进工作台
```

## 11. 与官网的衔接

```
官网 (深色营销站)  ──点「免费开始创作」──▶  工作台 (同一套色板，但更密)
```

- 色板、字体、圆角完全继承官网，用户不会觉得进了另一个产品
- 但**信息密度要高一档**：工作台的间距是官网的 60%，字号小一档
- 官网的光晕、大留白、动效在工作台里全部去掉 —— 干活的地方不需要氛围

## 12. 四个模式的差异速查

| | 短视频 | 短剧 | 教育 | AI App |
|---|---|---|---|---|
| 主输入 | 链接 / 文案 | 一句梗概 | 大纲 / 教材文件 | 一句需求 |
| 右栏 Tab | 成片·脚本·素材·设置 | 剧集·剧本·角色·设置 | 课件·视频·练习·设置 | 预览·代码·数据·部署 |
| 核心产物 | N 条竖屏成片 | 剧集树 + 角色库 | 三联产物 | 可运行应用 |
| 特有控件 | 批量网格 / 平台适配 | 剧集时间轴 / 角色锁定 | 讲师选择 / LMS 导出 | 设备切换 / 一键部署 |
| 生成策略 | 一次批量 N 条 | 先出 3 集再继续 | 整门课一次出 | 增量改，实时预览 |

四个模式共用同一套壳：左栏、对话流、输入区、状态规范完全一致，
只有右栏工作台的 Tab 和控件不同。新增第五条产品线只需要写一个右栏。
