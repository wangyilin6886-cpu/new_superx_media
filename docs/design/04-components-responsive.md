```

S   768     ▶ 所有「图文左右分屏」改为上下堆叠（图在上、文在下）
            ▶ 产品矩阵 2×2 → 1 列
            ▶ 导航收成汉堡 + 全屏抽屉
            ▶ 右侧章节进度轴隐藏

            定价对比表 → 分套餐折叠卡

```

移动端首页顺序不变，但**屏 04 产品矩阵上移的优先级更高**：
移动端在 Hero 下方直接放四色快捷入口条，避免用户滑太久。

## 3. 可访问性

```
· 正文对比度 ≥ 4.5:1；辅色在深底上用于文字时取 400 级而非 500 级
· 所有可点区域焦点环：2px brand-cyan，offset 2px
· 视频均可暂停；自动播放一律静音；提供字幕
· prefers-reduced-motion：关闭位移/视差/marquee/自动播放，仅保留透明度变化
· 图片全部带 alt；图标按钮带 aria-label
· 语言：简体中文为主，页脚提供 中文 / English 切换
```

## 5. 后续实现建议（等要写代码时再动）

```
框架     Next.js（App Router）+ TypeScript，静态导出即可，无需后端
样式     Tailwind CSS + CSS 变量托管色板（辅色按页面切换 data-theme）
动效     Framer Motion（进场/视差）+ CSS scroll-driven animations 兜底
组件     shadcn/ui 作底 + 自定义品牌层
内容     先写死在 content/*.ts；将来接 CMS 只换数据源
路由     /  /video  /drama  /education  /app  /about  /pricing  /cases  /contact
部署     Vercel / 静态托管；表单先用 mailto 或第三方表单服务占位

目录草案
  app/                页面路由
  components/ui/      按钮、卡片、标签、表单等基础件
  components/blocks/  Hero、ProductGrid、FeatureSplit、Workflow、FAQ、CTA…
  content/            文案与配置（四条产品线共用同一套 schema）
  public/media/       视频、图片占位资源
```

**关键设计约束**：四个产品子页面必须由同一组 `blocks` 拼装，
只靠 `content/` 里的数据 + 一个辅色变量区分。这样新增第五条产品线时，
只加一份数据文件即可。
