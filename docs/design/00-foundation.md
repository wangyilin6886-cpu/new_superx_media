## 1. 品牌定位

**SuperX** —— 一个 AI 内容引擎，四条产品线。

- 中文主张：**「一句话，生成一整条内容生产线」**
- 英文主张：**One prompt. A whole production line.**
- 副描述：SuperX 用同一套多模态生成引擎，覆盖短视频、短剧、教育课件、
  以及 Vibe Coding 应用生成四个场景。

四条业务线（对应四个子页面）：

| 代号 | 产品名 | 一句话 | 路由 |
|------|--------|--------|------|
| P1 | SuperX Reels | AI 输出短视频：脚本→分镜→配音→成片 | `/video` |
| P2 | SuperX Drama | AI 生成短剧：剧本→角色→连续剧集 | `/drama` |
| P3 | SuperX Learn | AI 教育：自动生成课件 + 讲课视频 | `/education` |
| P4 | SuperX Build | AI App / Vibe Coding：说人话造应用 | `/app` |

## 2. 视觉系统

### 2.1 基调
Dark-first（深色优先）。整站像一块「发光的黑玻璃」，
内容区用毛玻璃卡片浮在深色底上，产品线各自带一条辨识色。

### 2.2 色板

```
—— 中性 ——————————————————————————————————————
ink-900   #07070A   页面底色
ink-800   #0D0D14   区块交替底色
ink-700   #14141F   卡片底
line      rgba(255,255,255,0.08)   1px 描边
text-1    #F5F6FA   主文字
text-2    #A6A8B8   次文字
text-3    #6B6D80   辅助/脚注

—— 品牌 ——————————————————————————————————————
brand-violet  #6C4CF5   主色
brand-cyan    #22D3EE   渐变尾色
brand-grad    linear-gradient(100deg, #6C4CF5 0%, #22D3EE 100%)
glow          radial-gradient 紫青双色光晕，用于 Hero 背景

—— 产品线辅色（每个子页面主导色）——————————————
P1 Reels      #FF5A6E  珊瑚红
P2 Drama      #A855F7  剧场紫
P3 Learn      #34D399  知识绿
P4 Build      #F59E0B  琥珀橙
```

规则：首页统一用品牌紫青；进入子页面后，Hero 光晕、按钮、图标、
进度条切换成该产品线辅色，紫青退为次要点缀。

### 2.3 字体

```
标题（EN）  Space Grotesk / 700 / -2% 字距
标题（CN）  HarmonyOS Sans SC 或 思源黑体 / 700
正文        Inter + 思源黑体 Regular 400 / 行高 1.75
数字/代码   JetBrains Mono（指标数字、代码块、终端演示）
```

字号阶梯（桌面 / 移动）：

```
Display   72 / 40   Hero 主标题
H1        56 / 32   分屏标题
H2        36 / 26   卡片组标题
H3        24 / 20   卡片标题
Body-L    18 / 16   段落
Body      16 / 15
Caption   13 / 12   标签、脚注
```

### 2.4 栅格与间距

```
最大内容宽  1280px
列数        12 列，gutter 24px
页面左右留白  桌面 80px / 平板 40px / 移动 20px
区块上下留白  桌面 140px / 移动 72px
圆角        卡片 20px，按钮 12px，大容器 28px，标签 999px
阴影        0 24px 60px rgba(0,0,0,.45) + 内发光 1px line
```

### 2.5 动效规则

```
· 滚动进场：opacity 0→1，translateY 24px→0，360ms，cubic-bezier(.2,.8,.2,1)
             同组元素 stagger 60ms
· Hero 背景：循环生成画面拼贴，缓慢横向漂移（20s loop），50% 暗化
· 数字指标：进入视口后 0→目标值滚动，1.2s
· 卡片 hover：上浮 4px，描边亮度提升，辅色光晕淡入
· 品牌墙/案例：无限横向 marquee，hover 暂停
· 章节切换：右侧固定一条细进度轴，标出当前处于第几屏
· 全站尊重 prefers-reduced-motion，关闭位移与自动播放
```
