# SuperX 官网 · 四个产品子页面线框（02）

四个子页面共用**同一套骨架模板**，只替换辅色、文案、演示模块与行业场景。
这样既保证品牌一致，又让每条产品线有自己的气质。

## 通用模板（8 个区块）

```
S1  产品 Hero（辅色光晕 + 主张 + 双 CTA + 主视觉演示）
S2  痛点 → 解法 对照
S3  核心能力 3×2 卡片网格
S4  工作流可视化（该产品线的专属流水线）
S5  作品展示 / 交互式 Demo（各产品线形态不同，最具差异化的一屏）
S6  适用场景 / 行业
S7  案例 + 数据 + 客户证言
S8  定价锚点 + CTA + 交叉推荐另外三条产品线 + 页脚
```

子页面统一的交叉推荐条（S8 内）：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  还需要别的生产线？                                                          │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐                         │
│  │ ● AI 短剧    │ │ ● AI 教育    │ │ ● AI App     │  ← 当前页那条不出现      │
│  │ 了解 →       │ │ 了解 →       │ │ 了解 →       │                         │
│  └──────────────┘ └──────────────┘ └──────────────┘                         │
└──────────────────────────────────────────────────────────────────────────────┘
```
